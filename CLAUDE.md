## Project Overview

Tournament management portal for **MMPL (Mandirian Mobile Legends Professional League) Season 9**. A fully static web application — no build step, no server. Served directly from GitHub Pages or any HTTP server.

## Development Commands

**Regenerate team/roster data from Google Sheets:**
```bash
pip install -r requirements.txt   # only needed once; installs pandas
python sheet_to_json.py           # fetches CSV → writes mmpl.json
```

**Preview locally:**
```bash
python -m http.server 8000        # then open http://localhost:8000
```

There is no test suite, linter, or build pipeline.

**CI/CD:** `.github/workflows/sync.yaml` runs `sheet_to_json.py` on a schedule and auto-commits `mmpl.json` if changed.

## Architecture

### Data Sources & Flow

```
Google Sheets (team/roster data)
  → sheet_to_json.py (Python)
  → mmpl.json  ←── fetched by all HTML pages at runtime

Google Apps Script endpoint
  → returns MVP match records as JSON
  → fetched live by index.html and mvp.html
  → processMVPData() tallies points (winner +2, loser +1)
```

`mmpl.json` is the master data file — it holds all 37 teams across 4 groups (A–D), full rosters, and the MVP log. It is checked into git and regenerated by CI.

### Pages

| File | Role |
|------|------|
| `index.html` | Main SPA: Home / Teams / MVP / About tabs via `navigateTo()` |
| `mvp.html` | Standalone MVP leaderboard (duplicates MVP logic from `index.html`) |
| `teams.html` | Standalone teams list |
| `deb9a040-...html` | Password-protected MVP input form (password: `mvp9`) |

**Important:** MVP scoring logic exists in both `index.html` and `mvp.html`. If point values change, update both files.

### Frontend Stack

All libraries are loaded from CDN — no `package.json`, no bundler:
- **jQuery 3.7.0** — required only for DataTables integration
- **DataTables 1.13.6** — sortable/searchable team roster tables with expandable rows
- **html2canvas 1.4.1** — exports the MVP leaderboard as a PNG download

The codebase uses vanilla ES2020+ JavaScript with no transpilation.

### Key Runtime Variables / Constants

| Symbol | File | Value |
|--------|------|-------|
| `SCRIPT_URL` | `index.html` | Google Apps Script endpoint (MVP data) |
| `sheet_id` | `sheet_to_json.py` | Google Sheet ID for roster CSV |

### Network Resilience Pattern

All `fetch()` calls use an `AbortController` with a 15-second timeout and `cache: 'no-store'`. URLs append `?v=${Date.now()}` for cache-busting. Errors render a "Retry" link in place of the failed content.

### `sheet_to_json.py` Conventions

- Detects player columns dynamically: looks for any column named `Nama Lengkap`, `NIP`, `Nick`, `ID Game` (supports multiple slots per team row).
- Timestamps use Jakarta timezone (`Asia/Jakarta`, UTC+7) via `zoneinfo`.
- Output written to `mmpl.json` with `ensure_ascii=False` and `indent=2`.
